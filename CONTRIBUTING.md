# Como contribuir

Este é um repositório de demonstração. Sugestões de correção, acessibilidade e conteúdo são bem-vindas.

1. Abra uma issue descrevendo o problema e o resultado esperado.
2. Crie uma branch `feature/*` ou `hotfix/*` a partir de `develop`.
3. Rode `npm ci`, `npm run typecheck`, `npm test` e `npm run build`.
4. Envie o pull request para `develop` com um commit no formato gitmoji: `<emoji> <tipo>: <descrição>`.

Não envie dados reais de clientes, credenciais ou conteúdo de apresentação comercial.
